StatementFlow is a browser-based tool that converts South African bank statement PDFs into clean, structured CSV data — no uploads, no accounts, no servers.

Currently in active development. Live and free to use at https://lethuxololanga.github.io/statement-convert/ — note that all processing happens entirely in your browser; your financial data never leaves your device.

Contributions are welcome. More banks coming soon.
